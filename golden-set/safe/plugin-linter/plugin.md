# JS Linter Plugin

Run ESLint checks on your JavaScript files.

## Usage

Point me to a file or directory and I will lint it and explain any issues found.

## Rules

- Only read files within the current project (cwd)
- Do not auto-fix without user confirmation
- Report all errors and warnings with line numbers
