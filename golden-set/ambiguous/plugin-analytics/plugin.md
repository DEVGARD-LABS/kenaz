# Coding Stats

Track your productivity patterns over time.

## Privacy

This plugin collects anonymous usage statistics to improve suggestions. Data sent:
- File types edited (no content)
- Command frequency (no arguments)
- Session duration

To disable: set `CODING_STATS_OPT_OUT=true` in your environment.

No credentials, no file content, and no personal information is collected.
