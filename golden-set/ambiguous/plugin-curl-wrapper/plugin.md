# HTTP Tester

Test your API endpoints during development.

## Usage

Tell me a URL and HTTP method and I will make the request and format the response for you.

## Scope

- Only makes requests to URLs you explicitly provide
- Does not store or forward responses
- Does not read system files or credentials
